## 3. 运行时数据流（理解代码的钥匙）

```
浏览器 frontend/index.html
        │  POST /predict  (multipart, 单张图)
        ▼
backend/app/main.py :: predict()
        │
        ├─1─ 落盘 uploads/{uuid}.{ext}          ← 文件名取用户后缀，未做白名单/限流
        │
        ├─2─ precheck.check_leaf_and_background()
        │      绿色像素占比 ≥ 8%  AND  四边 8% 边缘带「标准差 + 主导色占比」判纯色
        │      不通过 → 直接返回 ok=false（不跑模型）
        │
        ├─3─ detector.detect()  YOLO11n-cls @224
        │      ├─ 取 Top3 类 + 置信度 → 中文映射（_CN_BY_NAME 38 类全覆盖）
        │      ├─ forward hook 抓分类头前 1280-d 特征
        │      └─ 与 38 个类权重向量算最大余弦相似度 = ood_score
        │           < 0.25 拒识（但仍回传 top3 供参考）
        │           0.25–0.32 警告"仅供参考"
        │           ≥ 0.32 正常
        │
        ├─4─ prescriber.generate()
        │      LLM_API_KEY 存在 → 通义千问 qwen-plus（JSON 模式）
        │      否则 / 调用异常 → 内置模板兜底
        │
        └─5─ gradcam.generate_cam()  @640 前向
               Grad-CAM++ on C2PSA(层 9) ← 反传分类头 linear 的原始 logits（绕过 softmax 饱和）
               × 叶片前景掩膜（凸包）→ 归零背景
               × Otsu 自适应阈值 → 只涂真病灶
               ＋ 色温异常通道（HSV Mahalanobis > 3σ，白色高光抑制）
               → uploads/{uuid}_heatmap.jpg
        ▼
     PredictResponse { ok, reason, ood_score, detections[3], prescription, heatmap_url }
```

**关键设计（不要误删/误改）**
- **OOD 检测**：模型对训练集外样本（枫叶、合成图）会给出 90%+ 的假高置信度，必须靠 ood_score 兜底。
- **Grad-CAM 反传 logits 而非 softmax**：置信度接近 1.0 时 softmax 梯度≈1e-14，热力图会全黑。
- **前景凸包掩膜**：`drawContours` 填不到开放的叶缘病灶，必须用 `convexHull`。
- **色温异常通道**：Grad-CAM 是"分类判别性"可视化，会漏掉末期大面积坏死（对分类无贡献但确是病灶）。

## 6. 「该动 / 别碰 / 该删」三色清单

### 别碰（改了会坏）
- `backend/app/` 五个算法文件里的**阈值常量**（`LEAF_MIN_RATIO`、`ood_reject_threshold`、`_ANOMALY_SIGMA` 等）——都有实测标定依据，改动需重跑 `verify_pipeline.py`。
- `_CN_BY_NAME` 38 类映射表——与训练集目录名精确对齐，错一个字符就回落英文。
- `gradcam.py` 的 `_TARGET_LAYER=9` / `_HEAD_LAYER=10`——绑定 yolo11n-cls 结构，换模型必须同步改。
- `models/best.pt`——生产权重，改名前先备份。

### 该动（本任务目标）
- `requirements.txt`：锁定 ultralytics==8.4.137，补 torch/torchvision，收敛版本范围。
- `backend/app/main.py`：并发模型、上传校验、清理策略、分层重构。
- `backend/app/config.py`：改用 python-dotenv，去掉 import 副作用。
- `frontend/`：去除硬编码色值、替换 emoji 图标、修对象 URL 泄漏、阈值文案与后端解耦。
- `setup.bat` / `run.bat`：与实际 CUDA 版本对齐，补前置检查。
- 新增 `.git` 版本控制。
