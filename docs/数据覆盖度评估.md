# 数据覆盖度评估

> 评估日期：2026-09-20 · 基于部署权重 `models/best.pt`（v2）与训练集 `data/plantvillage`（38 类 / 60,343 张）
> 用途：回答「现有数据能覆盖检测多少种类、达到何种程度、是否需要继续采集与训练」

---

## 一、一句话结论

**能识别 14 种作物的 38 个类别；其中只有 11 种作物具备病害诊断能力，
另有 3 种作物（蓝莓、树莓、大豆）只有健康样本、完全无法诊断病害。**
实验室同分布下精度极高（类别平均召回 **0.9967**、零误拒），
但**全部训练数据是实验室摆拍**，真实田间场景会大面积拒识。

**是否需要继续采集与训练：需要，但不是"数据量不够"，而是"数据结构性缺失"。**
详见第五节。

---

## 二、能覆盖多少种类

### 2.1 总量

| 指标 | 数值 |
|---|---|
| 可识别类别数 | **38** |
| 覆盖作物数 | **14** |
| 其中**具备病害诊断能力**的作物 | **11**（番茄、苹果、玉米、葡萄、马铃薯、樱桃、柑橘、桃、辣椒、南瓜、草莓） |
| 其中**仅能判"健康"**、无病害样本的作物 | **3**（蓝莓、树莓、大豆） |
| 可识别的病害/虫害条目 | **26** |
| 健康状态条目 | 12 |
| 有病害能力作物占比 | 11 / 14 = **78.6%** |

### 2.2 逐作物病害覆盖（这是最关键的一张表）

| 作物 | 类别数 | 可识别病害数 | 含健康类 | 病害覆盖 |
|---|---|---|---|---|
| 番茄 Tomato | 10 | **9** | 是 | 9 种（最完整） |
| 苹果 Apple | 4 | **3** | 是 | 3 种 |
| 玉米 Corn | 4 | **3** | 是 | 3 种 |
| 葡萄 Grape | 4 | **3** | 是 | 3 种 |
| 马铃薯 Potato | 3 | **2** | 是 | 2 种 |
| 樱桃 Cherry | 2 | 1 | 是 | 1 种 |
| 桃 Peach | 2 | 1 | 是 | 1 种 |
| 辣椒 Pepper | 2 | 1 | 是 | 1 种 |
| 草莓 Strawberry | 2 | 1 | 是 | 1 种 |
| 柑橘 Orange | 1 | 1 | 否 | 1 种（且无健康类） |
| 南瓜 Squash | 1 | 1 | 否 | 1 种（且无健康类） |
| **蓝莓 Blueberry** | 1 | **0** | 是 | **仅健康，无任何病害样本** |
| **树莓 Raspberry** | 1 | **0** | 是 | **仅健康，无任何病害样本** |
| **大豆 Soybean** | 1 | **0** | 是 | **仅健康，无任何病害样本** |

> **结构性盲区（务必知晓）**：蓝莓、树莓、大豆这 3 种作物，
> 模型在训练中**从未见过它们的任何病害样本**。因此若用户上传一张**患病的蓝莓叶**，
> 模型只有两种可能：判成"蓝莓·健康"（大概率），或判成别的作物（小概率）。
> 这两种结果**都是错的**，且不属于"拒识"——因为 OOD 分数可能仍在正常区。
> **这是当前覆盖面最需要修补的缺口。**

### 2.3 与中国农业实际的差距

| 缺口 | 说明 |
|---|---|
| **无中国主粮** | 不含水稻、小麦、棉花。PlantVillage 数据集本身就不含这三者，属数据源先天限制 |
| **无虫害** | 仅病害。训练集中 `Spider_mites`（红蜘蛛）一项算虫害，其余均为病害 |
| **作物偏欧美设施栽培** | 番茄、草莓、葡萄、辣椒等是设施农业主力，有真实应用场景，但覆盖面窄 |

## 三、达到什么程度（实测数据）

### 3.1 类别级召回（验证集，每类随机抽 8 张，共 304 张）

| 指标 | 数值 |
|---|---|
| 类别级平均召回 | **0.9967** |
| 召回 < 0.875 的类别数 | **0** |
| 唯一非满分类别 | 玉米·大斑病（7/8 = 0.875） |

38 个类别逐一抽样，**除 1 类外全部 8/8 命中**。混淆矩阵实测为干净对角线。

### 3.2 OOD 分布（同分布验证集，304 张）

| 指标 | 数值 | 含义 |
|---|---|---|
| OOD 分数均值 | **0.5136** | 远高于正常阈值 0.32 |
| 最小值 | **0.3188** | 仍高于警告阈值下限 0.25 |
| 最大值 | 0.6789 | — |
| **被误拒（< 0.25）** | **0 / 304 = 0.00%** | **同分布数据零误杀** |

这说明 OOD 阈值 0.25/0.32 与当前模型**匹配良好**，不会误伤受支持的作物。

### 3.3 数据量与均衡性

| 指标 | 数值 |
|---|---|
| train / val 总量 | 48,282 / 12,061 = **60,343** |
| 单类样本量区间（train） | 800 ~ 4,406 |
| 最大/最小类样本量比 | **约 5.5 : 1**（轻度不均衡，可接受） |
| 最小类样本量 | 800（多类被统一到 800，疑似做过过采样/上限截断） |

**数据量本身不是瓶颈**——60,343 张训练 38 类分类任务已相当充分，
且实测精度与零误拒说明模型已收敛。

### 3.4 现有精度指标的适用边界（答辩必须说清）

- **0.9967 是"实验室同分布"指标**：单叶、纯色背景、与训练集同源。
- **真实田间场景会大面积拒识**：早期实测田间/复杂背景图的 OOD 分数仅 0.17–0.20，
  低于拒识阈值 0.25，会被系统明确拒绝。
- 这不是模型缺陷，而是**训练分布决定的固有边界**；OOD 机制的价值正在于
  "知道自己不知道"，而不是假装什么都能认。

## 四、数据覆盖度的三种"程度"表述（供答辩选用）

1. **类别层面**：38 类 / 14 作物，实验室同分布召回 0.9967，同分布零误拒。
2. **作物层面**：14 种作物中 **11 种可诊断病害**，3 种只能判健康（蓝莓、树莓、大豆）。
3. **场景层面**：仅适用于"单片叶 + 纯色背景"的拍摄条件；田间实景会拒识——
   这是**主动划定的可信边界**，不是能力缺失。

---

## 五、是否需要继续采集与训练

**结论：需要，但优先级不是"加数据量"，而是"补结构缺口"。**

### 5.1 按优先级排序的建议

| 优先级 | 事项 | 为什么值得做 | 工作量与可行性 |
|---|---|---|---|
| **P0** | **补 3 种"仅健康"作物的病害数据**（蓝莓、树莓、大豆） | 这是**模型自洽性缺陷**：即使上传患病叶片也会判"健康"，是错误答案而非拒识。答辩被问"这 3 种作物能诊断什么病"会直接失分 | 每类补 200–400 张即可（够 nano 模型学习）。魔搭/天池可找；数据整理约 1–2 小时，训练 30 轮约 40 分钟 |
| **P1** | **补真实田间/复杂背景样本（几十张即可）** | 当前阈值是拿实验室图标定的；有真实场景样本才能**用数据说明"田间会拒识"**，而不是靠推断。也让"逐步放宽拍摄约束"的路线图有依据 | 自己拿手机拍即可，成本极低，收益很高（建议至少 30–50 张：支持作物与不支持作物各若干、不同光照背景） |
| **P2** | **补中国主粮（水稻、小麦、棉花）** | iCAN 是中国赛事，主粮缺失在"实用性"维度会被对比 | 需找新的标注数据源（PlantVillage 不含），且应作为**独立扩展包**而非混入主模型——**混入会打乱现有 38 类的 OOD 权重标定**。工作量以周计 |
| **P3** | **补虫害识别** | 竞品有病害+虫害双覆盖 | 属另一个技术方向（田间群体识别、诱捕时序），不是"加几类"能解决 |

### 5.2 明确不建议做的事

- **不要为了"类目更多"而混入新作物重训单一模型**：会破坏当前
  `_class_weights_norm` 的 OOD 标定（阈值需全部重标），且小样本新类会拉低整体。
  正确做法是**独立扩展包 + 路由**。
- **不要在赛前大规模重训**：当前模型已收敛且零误拒，贸然重训可能引入新的
  "模型坍缩"或阈值失配风险（历史上就发生过一次）。**重训后必须重跑
  `scripts/verify_pipeline.py` 与 `pytest tests`，并重新标定 OOD 阈值。**

### 5.3 若不补数据，答辩怎么答

诚实且有力的口径：**"我们宁愿只覆盖 14 种并保证可信，也不愿覆盖 23 种却让农民拿到错误处方。"**
配套动作：把上面的 P0–P3 作为**已规划的路线图**讲出来，并说明技术栈
（分类 + OOD + 可解释）**与作物无关，换数据即可扩展**。

> ⚠️ 但请注意：**P0 那 3 种"仅健康"作物属于"已覆盖但覆盖不全"**，
> 与"未覆盖主粮"性质不同——前者是内部不一致，后者是范围取舍。
> 若被问到，前者更难以自圆其说，建议优先补上或明确说明其状态。

## 六、结论速览（可直接用于答辩）

1. **能识别**：14 种作物 / 38 个类别，其中 26 个病害/虫害条目。
2. **达到什么程度**：实验室同分布下类别平均召回 **0.9967**、OOD 零误拒；
   真实田间会拒识（主动划定的可信边界）。
3. **明确边界**：蓝莓、树莓、大豆**仅有健康类**；不含水稻/小麦/棉花；仅病害不含虫害。
4. **是否要补**：数据量够，缺的是结构。建议按 **P0（补 3 种仅健康作物的病害）→
   P1（补真实场景样本标定阈值）** 的顺序补，主粮与虫害列入路线图。
