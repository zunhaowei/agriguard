### 其他注意
- 注意：`.venv` 的 `pyvenv.cfg` 中 `home` 指向的是**另一个 Windows 用户目录下的**托管 Python。**该路径会随用户账号变化而失效**，届时 `.venv\Scripts\python.exe` 会直接报 "did not find executable"。修法：把 `pyvenv.cfg` 的 `home` / `executable` / `command` 三行改成本机实际存在的 Python 路径即可（site-packages 无需重装）。此问题已于 2026-09-20 复现并修复。
