- 最终结果：只用增强版（原始版冗余），整理为 `data/plantvillage/{train,val}`：

## 重训模型：CUDA 环境配置 + 训练
- 硬件：NVIDIA RTX 4060 Laptop 8GB，驱动 592.00，CUDA 13.1。
- 原 venv 是 torch 2.13.0+cpu（无 CUDA），需装 CUDA 版。
- 安装 torch 2.13.0+cu126 + torchvision 0.28.0+cu126（阿里云镜像 pytorch-wheels/cu126）。
- 关键坑：
  1. 阿里云镜像对单连接限速约 0.43MB/s，多线程 Range 下载可达 3.4MB/s（16线程）。
     写了 `scripts/download_torch_cuda.py` 多线程下载器。
  2. torchvision 下载后 pip 安装成了 +cpu 版（旧残留），导致 `torchvision::nms` CUDA 后端缺失。
     需 `pip install --force-reinstall --no-deps <cu126 wheel>` 强制重装。
  3. ultralytics 8.4.137 的 `optimizer=auto` 选择 MuSGD，与 torch 2.13 有 view 兼容性 bug
     （`RuntimeError: view size is not compatible...`），第一个 epoch 崩溃。
     解法：`train_v2.py` 加 `optimizer="SGD"` 固定优化器。
  4. AMP 检查需下载 yolo26n.pt（github 被拦），跳过不影响（amp=True 仍生效）。
- 训练命令：`python scripts/train_v2.py --data data/plantvillage --model-size n --imgsz 224 --epochs 30 --strong-aug --device 0 --batch 32`（去掉 --balance，数据已较均衡，balance 只是复制浪费时间）。
- 训练参数：nano 1.58M 参数，48282 train + 12061 val，SGD，约 19.5 it/s，每 epoch ~77s，30 epoch 约 40-50 分钟。输出 runs/agriguard_v2/weights/best.pt。
- 训练完成后需把 best.pt 复制到 models/ 覆盖旧模型。
